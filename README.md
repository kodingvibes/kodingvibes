# 🚀 KodingVibes

Bienvenido a la organización de **KodingVibes**, el epicentro del *Vibe Coding* y la colaboración técnica.

## 🌟 Misión y Visión

**Misión:**  
Crear un ecosistema vibrante y dinámico donde los desarrolladores puedan compartir conocimiento, código y experiencias en un formato comunitario (estilo Reddit), eliminando las barreras entre la idea y la implementación.

**Visión:**  
Convertirse en la plataforma de referencia para la comunidad de habla hispana, impulsando la cultura del "Vibe Coding": la capacidad de iterar rápido, experimentar sin miedo y construir software que no solo funcione, sino que tenga "vibe".

## 🛠 Ecosistema de Proyectos

KodingVibes no es solo un sitio web, es una infraestructura distribuida de servicios:

### 🌐 Plataforma Core (`kodingvibes`)
El portal principal de la comunidad. Un espacio para publicar, votar y discutir sobre desarrollo de software, construido con **Next.js**, **TypeScript** y **Supabase**.

### ⚡ La Suite "Late" (Micro-servicios y Frontends)
Un conjunto de herramientas ligeras diseñadas para la comunicación y el monitoreo en tiempo real:
- **Late Micro-Chat**: Cliente de comunicación avanzada con soporte para IRC, WebRTC y notas de voz.
- **Late Micro-Dashboard**: Panel de control técnico para monitoreo de estado del sistema.
- **Late Micro-Radio**: Servicio de streaming y gestión de radio Icecast.
- **Late Auth & Chat Services**: El motor de backend en Python que sostiene la identidad y la mensajería del ecosistema.

### 📡 Infraestructura de Red (`late.kodingvibes.com`)
Capa de orquestación y relays SOMA que permite la interconectividad y el despliegue eficiente de los micro-servicios.
